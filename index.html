Unduh & Pasang
📱 Download untuk AndroidAPK (~3.8 MB) · aplikasi offline, putar media dari perangkat
  1. Unduh RiaMusic-Android-debug.apk lewat tombol di atas.
  2. Buka file-nya, lalu izinkan pemasangan dari sumber tidak dikenal bila diminta.
  3. Saat pertama dibuka, berikan izin akses media agar musik & video di perangkat dapat diputar.

Seluruh kode aplikasi dibundel di dalam APK (offline). Berkas musik/video tidak disertakan — diputar langsung dari penyimpanan perangkat.

💻 Download untuk WindowsZIP portabel (~0.6 MB) · shell WebView2
  1. Unduh RiaMusic-Windows.zip lalu ekstrak.
  2. Jalankan install.cmd untuk memasang ke %LOCALAPPDATA%\Programs\RiaMusic beserta pintasan Desktop/Start Menu — atau jalankan RiaMusic.exe langsung dari folder hasil ekstrak.

Prasyarat: Microsoft Edge WebView2 Runtime (umumnya sudah ada di Windows 10/11) dan .NET Framework 4.x. Data & playlist disimpan lokal di %LOCALAPPDATA%\RiaMusic\WebView2.

Aplikasi berjalan offline dengan kode yang dibundel di dalam paket. Fitur streaming (YouTube, radio, URL online) memerlukan koneksi internet. Halaman ini hanya menyediakan informasi dan unduhan.
